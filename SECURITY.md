# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead, use
GitHub's [private vulnerability reporting](../../security/advisories/new) on this
repository so the issue can be triaged before any details become public.

## Scope

CafeERP is a portfolio project maintained by a single developer. Reports concerning
the application code, its demo deployment, and its dependencies are welcome;
social-engineering and physical attacks are out of scope.

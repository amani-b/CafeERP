# Franken UI v2.1.2 — Verified Utility Class Reference

Compiled from the actual shipped `franken-utilities.min.css` / `franken-core.min.css`
(both present at the repo root as `css_classes.txt` source) rather than assumed from
Tailwind familiarity. **1376 classes** confirmed to exist in this exact CDN
build (`franken-ui@2.1.2`). This is the answer to the open question carried since the
original redesign passes: *is there a single source of truth for what's safe to use?*

## How to use this file

Before reaching for a utility class in a template, confirm it's in the list below.
If it isn't, it does not exist in this build — using it silently does nothing (no error,
no console warning, the class is just absent from the stylesheet). This is exactly what
happened to the pre-refactor `login.html` and `account/change-password.html`: classes like
`bg-gradient-to-br`, `from-stone-900`, `blur-3xl`, and arbitrary-value classes like
`top-[-10%]` were never real Franken UI v2.1.2 classes, so those two pages were rendering
without most of their intended styling in production. Both pages have since been rebuilt
using only verified classes plus `app.css` (see `docs/DESIGN_SYSTEM.md`).

**Not covered by this build at all** (confirmed absent, not just unused): shadow utilities, transform/transition utilities, gradient utilities, blur utilities, and arbitrary-value classes (`w-[500px]` etc). Anything in that category has to be raw CSS — which is what `app.css` is for.
